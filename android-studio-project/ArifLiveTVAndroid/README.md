# Arif Live TV — Android Studio Project

Android Studio wrapper for the Arif Live TV web interface.

## Build APK
1. Open this project folder in Android Studio.
2. Wait for Gradle sync and install Android SDK Platform 35 if prompted.
3. Choose Build > Build APK(s). Debug APK is under app/build/outputs/apk/debug/.

Source project only, not a ready-to-install APK. Use streams/playlists you are authorized to access.
